# 智能路由 Auto Router (dsh-auto-router)

单 API key、多模型的决策路由插件。在 DSH 模型选择器里注册虚拟模型 `bailian-auto`
（显示名「智能路由 Auto Router」）。选它之后正常提问即可：每次请求**先**由决策模型
分析输入的模态（文本 / 图片 / 代码）与任务类型（写作 / 推理 / 翻译 / 代码 / 看图 / 闲聊），
再转交给**你同一个 key 账号里**最合适的执行模型。

不绑定百炼：百炼（默认）、硅基流动、OpenRouter、火山方舟、智谱、Moonshot、DeepSeek 官方、
以及任何「一个 key 能访问多个模型」的 OpenAI 兼容网关都可用（见 README 支持平台表）。

## 功能

- **请求前主动决策**：默认决策模型 `deepseek-v4.1-flash`（可配）输出
  `{"selected_model": "...", "reasoning": "..."}`；无效答案自动回落启发式排序；决策超时不阻塞回答。
- **执行模型池**：只认账号 `GET /models` 真实返回的模型，不会凭空出现账号里没有的模型；
  与内置目录、用户自定义清单合并；面板按「图像 / 语音 / 推理 / 代码 / 写作 / 翻译 / 通用」**分类折叠**，点开才展开。
- **路由规则**：看图只从视觉模型里选；中文写作、代码/复杂逻辑、翻译各有优先族；候选列表可按任务类型自定义。
- **思考档位**：`auto / off / low / medium / high / max` 六档。按厂商分派参数：
  百炼/硅基/智谱走 `enable_thinking`(+`thinking_budget`)；OpenRouter/火山/DeepSeek/通用走 `reasoning_effort`（`max` 钳到 `high`）；
  Moonshot 不下发。模型拒参时自动去参重试，不整轮报错。
- **额度感知 / 容灾降级**：路由前查本地冷却；额度/限流/报错在未输出任何内容前静默换下一个；已输出内容则不再切换。
- **负载均衡**：同类候选按近期 token 消耗轮转，不盯着最强的薅；用量相近时优先更强模型；冷却中的模型不参与轮转。
- **多账号（选 API key）**：面板顶部下拉切换已保存账号；插件内可新增/编辑/删除账号（baseURL + key），
  切换后自动重新同步模型池；不选则用默认接口或自动沿用 profile 已有接入。
- **厂商预设**：`auto` 按接口地址自动识别，也可手动指定；决定思考参数写法与凭据环境变量顺序。
- **每模型额度上限**：给单个模型设用量上限，超了自动停用并路由下一个；不设即自动均衡。
- **一键完整性自检**：检查 key / 端点 / 模型池 / 客户端脚本 / 状态文件，能修的直接修。
- **状态与历史**：生效接口与凭据（打码）、模型池来源、每模型本地冷却（启发式，非后台真实配额）、
  连败与调用计数、最近 50 条路由决策（任务类型 / 决策来源 / 尝试链 / 原因）。

## 配置面板入口

- **插件页 → 本插件 → 配置区**（客户端面板挂在 `plugins.bundle.config` 插槽，key 为包名 `dsh-auto-router`）：
  决策模型、回退模型、超时、最大尝试、冷却、厂商预设、思考档位、均衡窗口、各任务候选、自定义模型池、账号管理、额度上限、自检按钮。
- **设置 → 模型** 底部另有一张状态小卡片（`settings.models.footer` 插槽）。

## 媒体端点（图像生成）

| 能力 | 处理方式 |
|---|---|
| 图像生成 | 可直接路由：说「画一张…/生成图片/配图」时调 `POST /images/generations`，落盘工作区 `.dsh-media/` 并回 Markdown 图片链接 |
| 语音合成 / 识别 | 网关 HTTP 面不提供时只登记不路由，面板显示数量 |
| 向量化 / 重排 | 非对话能力，保留在清单供检索类用途，不参与对话路由 |
| 视频生成 | 未接入：只做能力说明与替代方案（零 token），不调用视频接口 |
| 实时流 | 需 WebSocket 双向流，不适用于普通对话 |

## 状态文件

`~/.dsh/auto-router/state.json`（0.7.1 起自动迁移旧目录 `bailian-auto-router`；tmp + rename 原子写，单进程保证）。

`~/.dsh/auto-router/prefs.json`（0.8.0 起）：用户设置持久层。宿主配置全为 volatile、重启不序列化，
故面板/浮窗的每次成功编辑（排序、账号、连接中文名、限额、保存的账号等）都会镜像写入 prefs.json，
激活时水合回 volatile 引用；prefs 校验失败自动回退忽略，不破坏激活。与 profile 配置同级信任（含密钥，仅本机），不进日志/RPC/state.json。
