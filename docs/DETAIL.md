# 智能路由 Auto Router · 移动端 (dsh-auto-router-dshgo)

桌面版 `dsh-auto-router` 的 **dshgo 移动端移植**（engine ≥0.2.2-rc.1）。单 API key、多模型的决策路由：
在模型选择器注册虚拟模型 `bailian-auto`（显示名「智能路由 Auto Router」），每次请求**先**由决策模型
分析模态与任务类型，再转交给你同一个 key 账号里最合适的执行模型。

不绑定百炼：百炼（默认）、硅基流动、OpenRouter、火山方舟、智谱、Moonshot、DeepSeek 官方、
以及任何「一个 key 能访问多个模型」的 OpenAI 兼容网关都可用（见 README 支持平台表）。

## 移动端兜底

- 无可写文件系统时：生成图片改内嵌 data URI 返回，不整轮报错；状态持久化失败退化内存态。
- `os.homedir()` / `process.env` 不可用时自动回落，不崩溃。
- 真机剩余平台差异由 dshgo 自行适配修复后回传本仓库迭代。

## 功能

- **请求前主动决策**：默认决策模型 `deepseek-v4.1-flash`（可配）；无效答案回落启发式排序；超时不阻塞回答。
- **执行模型池**：只认账号 `GET /models` 真实返回的模型；面板按「图像 / 语音 / 推理 / 代码 / 写作 / 翻译 / 通用」分类折叠。
- **路由规则**：看图只从视觉模型选；写作 / 代码 / 翻译各有优先族；候选可按任务自定义。
- **思考档位**：六档 `auto/off/low/medium/high/max`，按厂商分派 `enable_thinking` 或 `reasoning_effort`；拒参自动去参重试。
- **额度感知 / 容灾降级**：本地冷却 + 未输出前静默换模型；已输出不切换。
- **负载均衡**：同类候选按 token 消耗轮转，用量相近优先更强模型。
- **多账号（选 API key）**：面板顶部下拉切换 + 插件内增删改账号（baseURL + key），切换后重同步模型池。
- **厂商预设**：auto 按接口地址识别，可手动指定。
- **每模型额度上限** / **一键完整性自检** / **状态与最近 50 条路由决策**。

## 配置面板入口

- 插件页 → 本插件 → 配置区（`plugins.bundle.config` 插槽，key 为包名 `dsh-auto-router-dshgo`）。
- 设置 → 模型 底部状态小卡片（`settings.models.footer` 插槽）。

## 媒体端点

图像生成可直接路由（移动端无 fs 时内嵌显示）；语音/向量化/重排只登记不路由；视频未接入（零 token 能力说明）；实时流不适用。

## 状态文件

`~/.dsh/bailian-auto-router/state.json`（目录名沿用旧 id 兼容既有状态；移动端写盘失败退化内存态）。
